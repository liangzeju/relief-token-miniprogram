- `setTaskActive` 的确切调用和事件现由回执验证器核验并写入资金领域。暂停任务拒绝新增资金分配和合同锁定，既有合同仍可按义务完成；清理合同后可关闭暂停任务。当前抽象合约仍没有正式任务关闭和采购付款入口。
