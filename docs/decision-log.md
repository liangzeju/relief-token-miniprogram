## 工程默认，非新增资金授权

- 未批准任务不参与分配，暂不允许应急预付或跳过验收。合同价格、数量、收款人、交付标准变更需要新版本与重签，历史批次引用原版本。
- 保留历史钱包，旧捐赠退款由原出资钱包授权；不能由管理员无凭证接管资金。
- 公开页面不披露注册个人资料；链上地址和交易可关联，不承诺地址匿名。
- 不新增个人寄送实物入口；平台采购的到货、验收和最终发放分别统计。
- 真正救援组织授权、现实交付、真实邮件、主网运营不能通过演示或测试币证明。

- 后端数据库字段和状态机
- API 请求/响应契约
- KYC/KYB/AML 规则
- H5 页面和按钮权限
- 主网部署和财务对账方案
