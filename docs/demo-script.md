# Demo 演示脚本

## 启动

```powershell
cd backend
npm start
```

打开：

- 移动端：`http://localhost:8787/mobile`
- 管理端：`http://localhost:8787/admin`

## 推荐演示顺序

1. 移动端展示 Demo/Testnet 标识、公开任务和资金动态。
2. 点击“登记捐赠”，提交一笔虚拟人民币到账申请。
3. 切换管理端，查看资金水印、任务队列、合同履约和链上动态。
4. 在“闭环演示控制台”点击“执行下一步”，按前置条件推进到账、合规、MON 存入、链上确认、任务核验、托管、交付、验收、结算、兑换、兑付和最终结算。每一步都会调用真实 API，并显示成功或业务错误。
5. 展示链上事件处于待确认状态，说明 Demo 不会转移真实 MON；需要时可用财务演示身份推进到 CONFIRMED。
6. 使用“重置演示”恢复固定初始数据，准备下一次展示。

## 演示边界

- 所有数据均为虚拟数据。
- Monad 仅使用 Testnet/演示适配器。
- 不接收真实人民币，不执行真实 MON 转账，不生成正式财务凭证。
