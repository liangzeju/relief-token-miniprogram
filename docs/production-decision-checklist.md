# 生产落地决策清单

> 历史生产清单，不是当前测试网待拍板列表。人民币和旧托管决策已替代。Gas 上限、余款和启动资金见 [决策记录](decision-log.md) Q01-Q03，不重复询问已确认事项。

当前项目是 Demo/Testnet 版本。以下事项不需要现在就提供账号或私钥，但在接入真实资金前必须由业务、财务和合规负责人确认。

## 需要业务方拍板

| 事项 | 需要确认的内容 | 影响 |
|---|---|---|
| 运营主体 | 谁收人民币、谁持有/托管 MON、谁签合同 | 法律主体、账户和审计归属 |
| MON 性质 | MON 是捐赠兑换媒介、服务结算资产，还是其他性质 | 会计、合同和合规流程 |
| 汇率规则 | MON/CNY 价格来源、快照时点、有效期、手续费 | 兑换金额和对账 |
| 资金用途 | 捐赠用途与任务类型、物资、地区的匹配规则 | 资金分配守卫 |
| 角色职责 | 上报、核验、调度、审批、验收、财务、合规的人员和机构 | RBAC 与职责分离 |
| 额度限制 | 单笔、单日、单机构、单任务额度 | 风险控制与灰度上线 |
| 公开范围 | 公开哪些金额、机构、地区、哈希和事件 | 隐私与审计展示 |
| 证据保存 | 合同、验收、支付回执和身份材料保存年限 | 对象存储和归档策略 |
| 争议处理 | 驳回、部分验收、退款、冻结、人工复核流程 | 状态机和客服/财务流程 |

## 需要外部服务配置

- 云服务商、域名、HTTPS 和部署区域
- PostgreSQL、Redis、对象存储和备份策略
- 登录方式：微信 OAuth、短信、账号密码或企业 SSO
- 支付机构及回调/对账接口
- KYC/KYB/AML 服务商
- Monad RPC、合约地址和 Relayer/HSM/KMS 方案
- 监控、日志、告警和消息通知服务

## 工程实施顺序

1. 先用本地 Demo token、模拟支付和 Testnet 完成全链路测试。
2. 再接 PostgreSQL、真实会话、对象存储和测试环境域名。
3. 接入支付沙箱、KYC/KYB 沙箱和 Monad Testnet Relayer。
4. 通过安全审计、账链银行三方对账和灾备演练。
5. 最后配置主网密钥、多签/HSM、限额和小额灰度。

## 不要通过聊天发送

云账号密码、支付密钥、RPC 私钥、Relayer 私钥、钱包助记词和个人身份材料都不应直接发给开发人员或写进仓库。生产密钥应放在云 KMS、Secret Manager、HSM 或多签系统中，只通过环境配置注入。
